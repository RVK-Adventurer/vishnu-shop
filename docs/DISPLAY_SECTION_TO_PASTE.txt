HOW TO USE THIS FILE
Your shop's client/store.config.json already has your own details, so don't replace that file.
Instead, add this "display" section to it on GitHub:

1. Open client/store.config.json on GitHub and click the pencil icon (Edit).
2. Find the line that starts with   "seo": {
3. Click at the very start of that line and paste everything between the two lines of dashes below
   (it ends with a comma, so the file stays valid).
4. Commit changes.
